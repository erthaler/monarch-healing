# Monarch Healing

Website for Monarch Healing (Monika Kulaga) — https://monarch-healing.com

Static site served by GitHub Pages. Edit `index.html`; photos live in `img/`.

## Pages
- `index.html` — public site and booking
- `account.html` — clients sign in with an emailed code, see and manage their sessions, add them to their calendar
- `admin.html` — practice view (admins only)

Shared: `styles.css`, `js/site.js` (content + connection settings), `js/app.js` (accounts, bookings, calendar).
Database and emails: see `supabase/SETUP.md`.
